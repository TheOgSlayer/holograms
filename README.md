# HologramPlugin

Floating text holograms for Paper 1.21+ (text display entities that always turn to face the viewer).
Good for NPC names.

Commands (permission `hologram.admin`, op by default): `/holo create <id> <text>`, `/holo delete <id>`,
`/holo list`, `/holo settext <id> <text>`, `/holo addline <id> <text>`, `/holo move <id>`,
`/holo offset <id> <up/down>`, `/holo scale <id> <size>`, `/holo tp <id>`.

Use `|` for a new line and `&` colours, including hex like `&#00a2ff`.
